## C. Томьёонууд

```
§1 Unit Price       = Purchase Amount / Purchase Quantity
§2 Сүүлийн худалдан авалт = эх сурвалж тус бүрийн ХАМГИЙН СҮҮЛИЙН САР
                            (нэг сард олон гүйлгээ → ЖИГНЭСЭН дундаж)
§3 Хамгийн хямд TOP 3, §4 хамгийн үнэтэй TOP 3   (тэнцвэл кодоор — давтагдана)
§5 Price Gap        = max − min ;  Gap % = (max − min) / min × 100
§6 Potential Saving = benchmark өртөг − (benchmark тоо × min unit price)
§8 Price Change     = (сүүлийн сарын үнэ − эхний сарын үнэ) / эхний × 100
```

⚠️ **Огноо байхгүй** (docs/01 §8) тул «сүүлийн худалдан авалтын огноо» = сар.
Нэг сар доторх дараалал тодорхойгүй тул санамсаргүй мөр сонгохгүй, тухайн
сарын жигнэсэн дундажийг авна.

⚠️ **§6-ийн хамрах хүрээ**: benchmark-д орсон мөрүүдийн тоо/өртгөөр тооцно.
Хасагдсан (тэг үнэ, буцаалт) мөрийг оруулбал хэтрүүлсэн хэмнэлт гарна.

## I. §13 Аудит

`POST /api/analysis/ai-recommendations/[id]/review`
Body: `{ action: ACCEPTED | REJECTED | MODIFIED, reviewedBy, newQuantity?, note? }`

Бичигдэх зүйл:
- `RecommendationReview` — action · reviewedBy · **oldQuantity → newQuantity** · note
- `AuditLog` — actor(user) · createdAt(date) · metadata.sku · entityId(recommendation) ·
  action · **before → after**
- `AIRecommendation.status` шинэчлэгдэнэ

`reviewedBy` **заавал** — аудитын бүртгэл нэргүй байж болохгүй тул API 400 буцаана.
MODIFIED үед `newQuantity` заавал, 0-ээс их бүхэл тоо.
