# Байгууллагын лого

Нэвтрэх дэлгэц болон толгой хэсэгт харагдах логог энд тавина.

## Файлын нэр

Дараах нэрсээс эхэлж олдсоныг нь ашиглана:

| Дараалал | Файл | Тэмдэглэл |
|---|---|---|
| 1 | `logo.svg` | ⭐ хамгийн тохиромжтой — ямар ч хэмжээнд тод |
| 2 | `logo.png` | ил тод дэвсгэртэй (transparent) байвал зохимжтой |
| 3 | `logo.webp` | |
| 4 | `logo.jpg` | ил тод дэвсгэр дэмжихгүй |

Нэмээд `logo-light.svg` (эсвэл `.png`) байвал **бараан дэвсгэр дээр**
түүнийг ашиглана — нэвтрэх дэлгэцийн зүүн талын хэсэг бараан тул
цагаан/цайвар хувилбар байвал илүү тод харагдана.

## Байхгүй бол

Систем унахгүй — байгууллагын нэрийг эмх цэгцтэй үсгэн хэлбэрээр
харуулна. Энэ нь **түр орлуулагч** бөгөөд албан ёсны лого биш.

## Байгууллагын нэр

`DSS_ORG_NAME` орчны хувьсагчаар өөрчилнө (анхдагч: `Монос ХХК`).

## Хэмжээ

- Өндөр 40–120 px орчим зурагдана, өргөн нь автоматаар тохирно
- Файлын хэмжээ 500 KB-аас бага байвал зохимжтой (base64-ээр хуудсанд шингэнэ)
